# ADR-005: Model selection and hosting

- Status: Accepted
- Date: 2026-11-10
- Deciders: AI lead, Architecture, Security, Head of Claims

## Context
Personal data and residency requirements.

## Decision
Use [model] hosted in [region] with no training on customer data; bank details never sent to the model.

## Consequences
Model swaps are releases and go through G3 again.
